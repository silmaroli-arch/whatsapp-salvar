# Salvar Mensagens

PWA para guardar conversas do WhatsApp (exportadas) e mensagens soltas. Dados ficam no navegador (IndexedDB).

- Conversas: importe o .zip/.txt gerado por "Exportar conversa" do WhatsApp.
- Mensagens soltas: via Compartilhar (Android) ou atalho (iPhone), ou digitando.

Testar local: `python -m http.server 8765` e abrir http://localhost:8765
